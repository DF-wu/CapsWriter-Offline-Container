# 公開報告頁設計

本頁是已授權的實驗報告交付，採現有報告資料生成單一靜態HTML，不改產品流程。使用 frontend-design 技能的兩階段設計與檢視。

色彩：霧白 #f4f7fb、深海藍 #142b46、鈷藍 #315fcb、訊號青 #167c80、退步紅 #a33e52、邊線 #d5e0ee。字體：中文系統黑體閱讀，Georgia／中文宋體標題，等寬數字僅用於量測值。版面：左側大幅「相容性已通過／品質未勝出」判斷，右側具條件標籤的WER比較；往下是可切換條件的圖、同runtime方案表、逐句文本、轉換流程與來源。單一波形形狀只作音訊主題識別，不用裝飾漸層。

已檢視：避免套用先前聊天小圖的暗色卡片堆疊；公開報告採寬版閱讀版型、以真實實驗條件與排除理由決定層級。所有作者FFASR資料另標作者宣稱，不混入本機量測。無外部字體、CDN、圖片或分析器。自包含，可離線，手機可讀，表格可橫向捲動。

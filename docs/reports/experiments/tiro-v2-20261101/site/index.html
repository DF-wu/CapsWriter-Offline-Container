轉換與量測細節

Decoder維持qwen3vl／28 layers／2048 embedding；tied output使用來源embedding。encoder所有learned weights都由來源BF16重新填入，只有deterministic sinusoidal position table沿用既有圖。Q5／Q4都從F16重新量化，未從原Q5升位元。

單請求、greedy temperature0、threads4、context2048、requested batch4096（runtime2048）、ubatch512、無context／aligner。每process排除暖機，block間冷卻至78°C目標，記錄前後snapshots與200ms telemetry。所有block驗輸出並查獨占條件，只有正常完成後接受資料。

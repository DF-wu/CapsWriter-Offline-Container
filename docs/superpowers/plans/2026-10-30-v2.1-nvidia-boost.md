# fork-v2.1.0 NVIDIA 預加速與發行準備

**目標：** 補齊 NVIDIA 預加速的 Linux、HTTP、設定與退出流程，準備可審閱的
`fork-v2.1.0` 候選；正式發布及 Portainer 部署不在本次操作範圍。

**設計：** 模型推論與 GPU boost 仍由單一 worker 管理。HTTP、桌面麥克風與
檔案任務在共用 dispatch 路徑啟動 boost；閒置與正常退出還原。
環境變數與保存設定只接受布林、數值；NVIDIA 命令以參數陣列執行。

## 操作限制

- 不啟停現有容器、不呼叫 Portainer API、不變更主機 GPU 時脈。
- 不刪除仍被掛載的 NFS 模型；myServices 中其他未提交變更不納入本次工作。
- 預設非 root 且 boost 關閉；鎖頻需要明確頻率、裝置及選用權限 override。
- 上游版本 `2.6` 保留，fork 版本獨立為 `2.1.0`。
- 不建立正式 tag、不發行 Release、不推送會自動發布 latest 的 master。

## 已確認的原始失敗

舊容器 UID 1000，NFS bootstrap lock UID 3000；模型掛載遷移 recipe 原本僅在
myServices 本機工作區，尚未推送，Portainer 因而仍使用舊掛載。這是 recipe
交付與部署切換問題，不能用 GPU boost 修復。v2.1 發布時需分別交付映像與
myServices recipe，明確驗證遠端 revision；刪除舊資料必須晚於掛載切換。

## 實機驗證限制

本次測試不得實際鎖頻。NVIDIA 文件指出 `-lmc` / `-rmc` 需要 root；Hopper
等架構對鎖頻方式另有限制。完成自動測試不代表已在使用者 GPU 證明效果。
正常退出可做有界還原；SIGKILL、主機斷電及驅動故障不保證執行清理。
